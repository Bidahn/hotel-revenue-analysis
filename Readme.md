# 🏨 Hotel Revenue Analysis & Power BI Dashboard

### By Bidhan Chitrakar

## 📌 About the Project

I created this project to explore hotel revenue performance and understand how data can help businesses make better decisions. My goal was to analyze historical hotel booking data, compare City Hotel and Resort Hotel performance, and build an interactive Power BI dashboard to present the findings clearly.

I used SQL Server to organize and analyze the data and Power BI to turn the results into meaningful visualizations.

Through this project, I focused on understanding revenue trends, hotel performance, booking patterns, and other key business metrics.

## 🎯 Project Objectives

- Analyze hotel revenue trends across different years.
- Compare revenue performance between City Hotels and Resort Hotels.
- Understand Average Daily Rate (ADR) and booking patterns.
- Analyze total nights booked and discount trends.
- Explore parking space demand and utilization.
- Build an interactive dashboard to support data-driven decision-making.

## 🗂️ Dataset Overview

The dataset contains historical hotel booking information covering two hotel categories:

- **City Hotel**
- **Resort Hotel**

The analysis focuses on booking and revenue-related metrics over multiple years.

## 🛠️ Tools & Technologies

- **SQL Server** — Data querying, aggregation, and analysis
- **SQL** — Extracting insights and calculating business metrics
- **Power BI** — Dashboard design, visualization, and interactive filtering

## 📊 What I Analyzed

### 1. Revenue Trends
Analyzed revenue performance over time to identify changes in hotel revenue and periods of higher demand.

### 2. Hotel Type Comparison
Compared City Hotel and Resort Hotel revenue contributions to understand differences in their business performance.

### 3. Average Daily Rate (ADR)
Examined ADR to understand pricing patterns and differences between hotel categories.

### 4. Booking & Night Analysis
Explored the total number of nights booked to better understand accommodation demand.

### 5. Discount Analysis
Reviewed discount-related data to explore how pricing adjustments varied across bookings.

### 6. Parking Demand
Analyzed parking space requirements as an additional operational metric.

## 📈 Power BI Dashboard

The dashboard brings the main findings together in an interactive report.

**Dashboard features include:**

- KPI cards for high-level performance monitoring
- Revenue trends over time
- Revenue distribution by hotel type
- Filters for date, hotel type, and country
- Visual comparisons of key hotel performance metrics
